# Mochi — illustration v2

Fichier livré : [`mochi-v2.png`](mochi-v2.png), PNG RGBA 1210 × 1300, avec transparence. Génération le 26 octobre 2026 avec l’outil intégré `image_gen`, mode création, `transparent_background: true`. Aucun recours au CLI ni à une API facturée depuis le projet. L’illustration générée a été copiée sans retouche dans les assets de l’application.

Ce personnage remplace les formes SVG du compagnon dans l’accueil, les situations, la conversation et la progression. Les icônes et les illustrations de café et de train gardent leur SVG. L’image est embarquée dans les exports web, iOS et Android ; aucune requête à un service d’image n’est nécessaire à l’usage. Il s’agit d’une illustration fixe, pas d’un personnage animé ou synchronisé avec la parole.

La proposition artistique reste à apprécier par le propriétaire sur le rendu intégré. Elle ne reproduit aucun asset de Pingo ou de Duolingo.
